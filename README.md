# Web3 Carnival: website redesign

A concept redesign of [web3carnival.world](https://web3carnival.world/), made for the GDG's **Kalakriti: Design Your Heart Out** competition.

Web3 Carnival is a festival of Web3 events rather than a single conference: a flagship week of themed Cons in Bengaluru (December 2023), then stops in Dubai, Singapore, Delhi and across India. The redesign leans on that idea. The site reads like a festival bill, with the official wordmark as the hero, tickets for events, a destination board of past stops, and a role filter that sorts the programme around the visitor.

![Home page, first viewport](docs/screenshots/desktop-home-hero.jpg)

**Deliverables**

- **Website:** ten routes plus a 404, built with Next.js 16 and Tailwind v4 (screenshots below).
- **Company overview deck:** 13 slides in the same brand kit, presentable at `/deck` and exported as a [PDF](public/docs/web3-carnival-company-overview.pdf). See [Company overview deck](#company-overview-deck).

## Company overview deck

A 13-slide company overview built with the same brand kit as the site: the vector wordmark, the Soft Carnival palette, the gradient grounds, the ticket motif and the real content from the site's data.

- **Present it:** run the site and open `/deck`. Use the arrow keys, Page Up and Page Down, or Space to move between slides; the URL remembers the current slide.
- **PDF:** [docs/web3-carnival-company-overview.pdf](public/docs/web3-carnival-company-overview.pdf) (16:9, 13 pages), also served at `/docs/web3-carnival-company-overview.pdf`.
